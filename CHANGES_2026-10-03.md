# 2026-10-03 IPC warning / font revision

This revision extends the modular Ford IPC tester with the requested warning behavior.

## Native cluster fonts

- The renderer uses the original Ford Antenna OTF/TTF files through SDL_ttf/FreeType.
- Text is rasterized at the internal high-DPI render scale instead of using a fixed glyph atlas.
- `extract_cluster_fonts.py` extracts the fonts locally from the user's IPC firmware package into `assets/ford_ipc/private_fonts/`.
- Raw font files are not redistributed in this archive.

## Yellow popups

- Washer Fluid Level Low
- Full Accessory Power Enabled
- See Manual (wrench)

## Red popups

- Powertrain Malfunction
- Engine Over Temperature
- Engine Oil Pressure Low
- Charging System Malfunction
- Door Ajar

Every popup includes an OK affordance in the bottom-right and SCCM/keyboard OK dismisses the active popup.

## Door-open popup

- Triggers on each passenger-door closed -> open edge only.
- Door-close transitions do not create popups.
- Uses the top-down vehicle artwork.
- Each door is a separate transparent layer with its own hinge pivot.
- The newly opened door swivels outward while doors already open remain in their current open state.

## CAN mapping policy

Verified signals remain live. `EngSrvcRqd_B_Rq` is treated as the yellow wrench / See Manual request, and the verified oil-pressure request drives Engine Oil Pressure Low. Red Powertrain Malfunction, Engine Over Temperature, and Washer Fluid Level Low remain UI/state hooks until their exact CX482 live signal mappings are verified; the project does not invent CAN bits for them.
